# 功能模块清单 · Feature Modules

> **English abstract.** YiChen ToDo is a local-first desktop to-do app for Windows and macOS built with Electron. Its
> defining trait is that it stays invisible: when idle it is only a small draggable marker, and the panel unfolds on
> click. This document is the authoritative feature scope, organized into 13 modules where every item is tagged
> **P0** (MVP), **P1** (before 1.0) or **P2** (after 1.0). Detailed content is currently Chinese-first.

**M04 进度**（P0 切片已交付，2026-10-20；设计与纪律见 [ARCHITECTURE.md](ARCHITECTURE.md) §5.3）：

- **交付形态是"两者都要"**：先发系统原生通知（Windows toast / macOS 通知中心），点击即应答并把面板打开到对应任务；若数分钟内仍无人应答，再浮出**应用内置置顶卡片**（面板顶部，带"完成 / 知道了"两个出口，前者就是列表勾选那一次写入）。**两套逻辑都写了，且做了去重**：一个提醒是一个实例一行数据，那行就是全部协调——点击 toast 把实例置为 `dismissed`，卡片定时器开卡前重读该行、发现已不是 `fired` 就什么都不做；反过来应答卡片时顺带关掉仍在的 toast。卡片**不抢焦点**（`expandPanelForReminder` 省掉 `focus()` / `moveTop()`），因为它正是用来兜底一个没人应答的通知，夺走光标就违背了初衷。
- **`reminders` 表终于有消费者**：它不是"用户的意图"而是**生成的实例**——意图是任务行上的 `remind_lead_min`，实例是 `fire_at = due_at - lead`。写任务时 `syncReminder` 重算这个等待实例，已完成 / 已取消 / 在回收站的任务没有等待实例，删除连带清除，撤销新建同样清除；已触发过的实例不再被改写（那是"说过什么"的流水）。重复任务每次展开生成独立实例，所以每个新 occurrence 自带自己的提醒。
- **调度器 `services/scheduler.ts` 落地，形态即文档所写**：单一时间源、**非轮询**——读最近的 `fire_at` 排一个 `setTimeout`，触发后重排（`setTimeout` 的 32 位毫秒上限被切成 `MAX_TIMER_MS` 片段）。它不 import electron：交付回调由 `main/index.ts` 注入 `platform/notifications.ts`。开机时把逾期超过 6 小时的 `pending` 实例标为 `dismissed` 而非补发（晚几小时说有意义，晚几天说只会有害）。
- **提前提醒档位**：5 / 10 / 30 分钟、1 小时、1 天画成 chip（`REMIND_LEAD_PRESETS`），按 `leadBucketOf` 说"分钟 / 小时 / 天"（不会把 1440 端给用户看）；原来的数字输入框保留在 chip 下方并在旁边补了单位，`data-field="detail-remind"` 未改动。
- 质量门：单测 **265 例**（新增 `fireAtFor` / 档位分桶、`reminders` 仓储的全状态流转、调度器的手工时钟推进与去重）；冒烟 `smoke:tasks` 从 76 扩到 **86 项**——新增 phase 12，用 `YICHEN_SMOKE_REMIND_OFFSET_MS` 把调度器时钟推快三天（时序算术不变，只是那一刻已经到来），断言"无截止不武装 / 无提前量不武装 / 档位 chip 武装出正确的 `fire_at` / 实例落成 `fired` / 卡片真的画在 DOM 上 / 应答后行成 `dismissed` 且卡片消失 / 整轮只播报一次也只应答一次"。
- 未完成：`snooze_until` 列已就位但**卡片上不提供 Snooze 按钮**（P2，见 M04 表末行）；逾期与汇总提醒、免打扰时段仍属 P1/P2。

## MVP 边界

**只做**：M01（含多显示器与吸附）+ M02（不含自然语言解析）+ M03（智能清单 / 自定义清单 / 搜索）+ M06（15 语种）+ M07（亮暗色 + 自定义主色 + 标记外观）+ M10（基础项）+ M11（签名打包与正式产物）+ M12（全部配套）+ M13（数据层与核心单测）。

**先不做**：贴边自动隐藏、自然语言解析、统计面板、番茄钟、日历 / 看板、本地 API、本地加密；内置主题先出 2 套。

理由：M01 的"标记拖拽 + 吸附 + 展开动画 + 低耗"是全项目最容易被判定成败的地方，先把这条体验链做透，其余都是可增量叠加的常规功能。
