# 功能模块清单 · Feature Modules

> **English abstract.** YiChen ToDo is a local-first desktop to-do app for Windows and macOS built with Electron. Its
> defining trait is that it stays invisible: when idle it is only a small draggable marker, and the panel unfolds on
> click. This document is the authoritative feature scope, organized into 13 modules where every item is tagged
> **P0** (MVP), **P1** (before 1.0) or **P2** (after 1.0). Detailed content is currently Chinese-first.

## MVP 边界

**只做**：M01（含多显示器与吸附）+ M02（不含自然语言解析）+ M03（智能清单 / 自定义清单 / 搜索）+ M06（15 语种）+ M07（亮暗色 + 自定义主色 + 标记外观）+ M10（基础项）+ M11（签名打包与正式产物）+ M12（全部配套）+ M13（数据层与核心单测）。

**先不做**：贴边自动隐藏、自然语言解析、统计面板、番茄钟、日历 / 看板、本地 API、本地加密；内置主题先出 2 套。

理由：M01 的"标记拖拽 + 吸附 + 展开动画 + 低耗"是全项目最容易被判定成败的地方，先把这条体验链做透，其余都是可增量叠加的常规功能。
